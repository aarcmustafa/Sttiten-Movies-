# 🎬 Sttiten Movies

تطبيق مفتوح المصدر لمشاهدة الأفلام والمسلسلات مع دعم كامل للترجمة العربية.

---

## ✨ الميزات

- 🎥 تصفح الأفلام والمسلسلات بالعربية
- 🔍 بحث متقدم مع فلاتر (السنة، التصنيف، التقييم)
- 🌍 واجهة عربية بالكامل (RTL)
- 📝 تحميل الترجمات العربية تلقائيًا
- ⭐ قائمة المفضلة والمشاهدة لاحقًا
- 📊 تتبع الحلقات المشاهدة
- 🌙 وضع ليلي / نهاري
- 🔐 نظام حسابات مستخدمين

---

## 🏗️ البنية التقنية

| الطبقة | التقنية |
|--------|---------|
| **Backend** | FastAPI + SQLAlchemy + PostgreSQL |
| **Frontend** | Flutter (Android / iOS / Web / Desktop) |
| **بيانات الأفلام** | TMDB API |
| **الترجمات** | SubDL + OpenSubtitles |
| **المصادقة** | JWT |
| **النشر** | Docker + GitHub Actions |
